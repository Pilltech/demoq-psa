# ADR-0012 · MCP server design

**Status:** S2 shell implemented; OAuth in S4. The MCP server is a stateless streamable-HTTP handler on Fastify
(`@modelcontextprotocol/sdk` 1.x, `sessionIdGenerator: undefined`, JSON responses), mounted at `/mcp`. Tools are
generated from the core registry (`exposeTo ∋ mcp`, name `resource_action`, JSON schema from the zod input), so MCP
runs the same `execute()` as the screens (Q-28) and every call is audited by name with the client label (Q-29).
S2 authentication: personal access tokens (`dq_pat_…`, SHA-256 at rest, ≤ 30 days, revocable, read-only for
privileged roles, 60 calls/min). S4 adds OAuth 2.1 via `oidc-provider` (CIMD + pre-registered Cowork client, no open
DCR, TOTP at consent). High-risk approvals return `DECIDE_IN_APP` (INV-19).
